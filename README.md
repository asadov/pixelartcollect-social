# Pixel Art Collect — social media files

Images and videos for scheduled posts of [@playpixelartcollect](https://www.instagram.com/playpixelartcollect/), served with GitHub Pages so the scheduling tool can fetch them.

Files are added only when their post is approved for scheduling. The game: [Pixel Art Collect on the App Store](https://apps.apple.com/app/id6818600929).
